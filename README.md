# scoop-bucket

A [Scoop](https://scoop.sh) bucket for the Amfelt agent, `amfelt`.

**Status:** no manifest is published here yet. The bucket cannot install the agent today.

The manifests will be generated from the Amfelt release channel at `https://releases.amfelt.com`: the URL and the sha256 of each archive come from the channel's signed checksums file. Do not edit the manifests by hand.

The agent is licensed under the Amfelt binary EULA: <https://releases.amfelt.com/LICENSE-BINARY>. This repository holds manifests only.
